📱 Contact Book Using Python Dictionaries

📌 Description

This project is a simple command-line Contact Book created using Python. It uses dictionaries to store and manage contact information.

✨ Features

➕ Add a new contact

🔍 Search for a contact

✏️ Update contact details

🗑️ Delete a contact

📋 Display all contacts

✅ Check for duplicate contacts


🛠️ Technology Used

Python

Dictionary

Loops

Conditional Statements


🎯 Objective

The main objective of this project is to understand Python dictionaries, key-value pairs, and basic CRUD operations through a practical application.


📚 Learning Outcome

Through this project, I learned how to use Python dictionaries to store, access, update, and delete data in a simple real-world application.
